## 这套指南解决什么

D2R mod 看似改几个 json，实则有一堆"凭直觉必翻车"的坑：改了不显示、启动 20 秒闪退、名字图标对不上、特殊符号变空白方块……本库把这些**已验证**的规律固化成标准，让你（或 AI）能：

1. **看懂**任意 D2R mod 的全部内容（→ `01_mod_anatomy.md`）
2. **不踩雷**地修改（→ `02_golden_rules.md`）
3. **不猜不臆造**地拿到正确数据（→ `03_data_sop_and_codes.md`）
4. 做出**高质量染色/排版**（→ `04_styling_colors_symbols.md`）

## 三条最重要的铁律（先记住这个）

1. **改对文件**：CN 客户端不同显示内容读不同文件——名字可能走 `bnet.json`、描述走 `item-modifiers.json`、其余走 `item-names.json`。改错文件 = 白改。（详见 `02`）
2. **绝不猜代码/ID**：物品代码反直觉（如无瑕宝石多数是 `gl*` 不是 `gz*`）；缺 `id` 字段会让游戏启动 ~20 秒后无日志闪退。永远从权威源 grep+提取。（详见 `03`）
3. **每条字符串必须带 `id`，简中写 `zhCN`**：国服客户端读 `zhCN`（旧说"必须 sgCN/bnCN 三字段"已实证翻案——原版数据无此字段，JCY/MDK/ComG 均不带照常运行；仅继承 SU 系文件时需把已存在的 sgCN/bnCN 旧值一并改掉）。（详见 `02`/`06`）

## 写入纪律（本库的元规则，防回音室）

> 本库出过两次"未验证结论被当铁律转抄"事故：**ÿcT 误标天蓝**（社区三表互抄）、**sgCN/bnCN 三字段同步**（一次误归因被全库转抄）。两者都是**回音室谬误**——结论在文档间互相引用、却无人能指出原始实测。纪律：

- **任何"铁律"必须能指向原始证据**：本机游戏内实测截图，或 vanilla 提取件中官方自己的用法。指不出 = 标"待验证"、禁止上生产。
- **社区资料（色码表/论坛帖）只在数字码层面可参考**；字母色码、新版本特性以游戏实测为唯一权威。
- **参考 mod 的工作目录 ≠ vanilla**：mod 作者可能改过 enUS/字段，引为"官方证据"前必须回到 CASC 原版提取件核对。
- 建议给每条结论标证据级：✅游戏实测 / 🔬参考 mod 生产性实证 / 📐文件结构事实 / ⚠️未验证（禁产）。
